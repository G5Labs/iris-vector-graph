# PPR source/proof architecture assessment

This follows [pre-candidate expectations](ppr-review-expectations.md). The
semantics-frozen103-unit candidate was inspected before final control replay.
Final acceptance and byte freshness remain separate replay obligations.

The source chain is retained mathematically: raw graph/node rows -> scoped
members -> distinct valid seeds -> raw eligible multiplicity slots -> scatter
and dangling score -> seed restart -> repeated change/held stopping -> scored
producer limit -> full or sparse-plus-zero reader. No normalized matrix, supplied
mass, score map or convergence Boolean decides the recurrence. The different
gather Fraction oracle is observation-only in the binding.

`prepare` derives its seed domain; `theorem_raw_preparation_closed` derives hop
endpoint closure from explicit node-key/edge-endpoint premises. Each raw optional
count means one when absent, otherwise that many slots. Forward/reverse slots
have weights1/w, while the divisor is the number of slots. Excluding a predicate
removes its numerator and denominator contribution together. Typed prefix parsing
and native grouping/mirror/count fidelity remain provider boundaries, rather than
being smuggled in as an already normalized transition matrix.

`scatter/ship` establish the finite-sum recurrence algebra and restart closes the
dangling mass. The generic step law is1-alpha+alpha*sum(old), conditional on
forward/unit-reverse traversal and closure. Initial uniform mass plus repeated
steps gives1; the two-node reverse witness independently derives(w/2,1/2) for
positive w. Native5 nonunit masses are retained, so no false universal mass1
claim is made for that documented extension.

Dense zero coordinates make the exact old/new L1 delta include disappearing
native map entries without requiring literal sparse-map equality. Held counts
nonzero new scores; the strict threshold and iteration cap control installation
and stopping. Zero and negative tolerance remain accepted as source supports.
The cap derives finite termination; no infinite convergence, approximation error
or universal numerical equivalence is proved.

The two readers preserve the actual semantic split. `source_limit` retains
None versus Some([]), producer1000, explicit positive caller top, and unlimited
effect for nonpositive limits. Fast completion sorts/caps sparse producer rows,
then appends current missing IDs at zero; full fallback sorts the complete map
before cutting. The tiny-positive theorem derives the conflicting selected set
from raw seeds/edge and ideal decimal buckets, without choosing q008's policy.

The strongest cap theorem is generic for every distinct N>1000 node list, each
node an isolated valid seed. It derives positive uniform initial and one-step
scores, the public request, producer1000 and finite-cardinality missing ID, then
exhibits its false zero in the final answer. Its helper accepts a positive map,
but the public theorem **derives** that map from raw data. It does not restrict
top<=1000 or supply the desired missing-membership answer. A legitimate smaller
cut losing mass is correctly kept as a passing neighbor.

Important scope qualifications in NOTES are accurate:

- Normal native Adj.Degree equality and correct/fresh score cache are external.
  Actual `_execute_ppr` executes over a provider that bypasses `_cached_algorithm`;
  an always-computing adapter proves no cache-history property. Ordinary Degree
  rollback is not conflated with the distinct algorithm-cache finding.
- Native correspondence requires unique grouped coordinates, faithful mirrors,
  positive completed keyed counts and stable closed rows. The algebra supports
  count0, but zero-valued native map presence/underflow is not a correspondence
  theorem. Store RunJson may keep explicit zeros; classfast filters>0. This is
  retained as a limit, not an invented public refusal or ordinary-writer bug.
- `decimal12` is ideal real half-even bucketing over integer-ordered atoms;
  binary rounding, native $Normalize, arbitrary string/canonical-number carriers
  and SQL enumeration are finite/provider observations. The body/JSON/name parser
  is not verified by this proof.
- Request.iterations has an integer carrier. Actual accepted whole-float1.0/2.0
  reaching fallback range TypeError is retained and deferred, not hidden or newly
  adjudicated. Formal public reader models the kg method; ppr()'s later raw-score
  stable sort is a separately observed actual wrapper.

The real fallback is observed unchanged with sys.settrace at its installed
change/held line; SQLite executes its SELECTs and final zero-fill node reads.
The native class implementation is explicitly a line-oriented source port.
Public missing-method fallback is actually dispatched in process; native missing
provider deployment is not claimed. Existing cache hits/F1004, global F1003,
new103/104 and q008 remain distinct.
