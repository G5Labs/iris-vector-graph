## Deciding chain and reader review

The relation starts from raw registry records/fields, registry error code/message,
own cache map and lookup/write clock samples. It filters graph/model/kind, discards
short rows, preserves first tied minimum preference, decodes fields and writes
only decoded rows. A decoded tableNone row is cached; readable absence, absent
registry and all-short replies are different branches. Current backend changes
or errors are hidden by a positive cache hit until strict expiration or local
invalidation. Raw later publication is not a proof of the DDL/transaction writer.

The scenario constructor retains the original registry, graph and normalized
model across phases and fixes node kind. It allows different raw provider replies
and clock samples, rather than allowing a fallback to change request identity.
Graph/model/table normalization is still an admitted codec/provider relation.

Query width comes from raw characters through the stack/lexer, including nested
objects/arrays, escapes, empty arrays and Python JSON nonfinite extensions. Width
is the outer element count, independent of numeric validity. Catalog functions
derive their **heuristic** result from raw LEN/control-byte/INFO cells, with
nonzero route width preceding catalog access. Neither a supplied count/mismatch
flag nor physical catalog truth decides preflight. Source matching to stdlib JSON
is inspected and finitely tested, not a machine-checked universal grammar theorem.

The search machine preserves Primary→Optimized→Client ordering, per-entry route
and preflight, primary dtype before width, seed expansion, immediate primary257
diagnosis, embedded/DBAPI typed readers, array-construction failure, client reads,
per-row kernel attempts and final stable score sorting. Rank2/1/0 proves model
termination without inventing a runtime retry budget. SQL ranking/numeric rows and
NumPy array/kernel replies are named providers; final row presence/arity/float
decoding remain actual readers. Array construction is separate from raw JSON
syntax, so a valid ragged array may fail before ClientVectorRead.

IVF shares node routing but has its own validation/dependency/admission sequence,
cursor/read effects, raw unrewritten local arguments, vector shape and persistent
Build/AddBatch/Finalize/Info prefix. Malformed Info cannot update either local
index map; valid JSON `null` can publish and return PythonNone. The formal returned
Info text is a syntax/content projection, not a theorem about an opaque provider's
whole decoded Python object, JSON serialization or native index contents.
