## Follow-up from the actual cache-writer census

H6 is explicitly later source discovery before extending the model: `_run_cypher` is the only current production caller of `_reset_engine`. A cached query exception on an ordinary `/api/cypher` request resets/closes the cached engine and retries once, changing what the next `/health` sees. A nonempty `IVGResult.error` is raised after the loop and does not reset; the same folded-error engine therefore remains for the next health request. A second exception stops after the one retry and leaves the replacement cached. This is a necessary competing-writer boundary, not a request to model arbitrary Cypher execution, authentication or write semantics.
