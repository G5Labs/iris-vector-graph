# Proposed full-record architecture — awaiting canonical-owner readiness

Input is finite raw parent/label/property/edge row sequences, ordinary graph/request ID carriers and raw qualifier text. A stable-view/normal-key frame supplies only real SQL facts such as unique (graph,ID) parents and unique raw property keys; it supplies no selected IDs, records, key order or result. Numeric/text storage is node_read's admitted Stored carrier; ordinary identifiers/keys are ordered ASCII atoms with explicit provider correspondence. The raw child-row sequence represents delivered SQL order, not canonical database ordering. No prohibited boundary expansion is needed.

Hydration initializes the actual requested-ID map, folds matching raw labels and properties, derives reserved-name aliases, runs the imported scalar read relation and performs raw-parent existence for records without children. A derived key enumeration and raw child map will discharge bulk_children's supplied reader_order premise on its integer identity subfragment; full new typed records use the actual computed field fold. Request order/repeats are recovered only after the map fold. Structural ID/labels stay disjoint from aliased properties. Generic field provenance/completeness and last-alias-winner lemmas are the main obligation, not an old map-lookup wrapper.

The default export node census filters raw parents and orders IDs by the source SQL-order abstraction. It calls this derived single-node hydration and constructs node events with structural ID/labels and projected properties. Edges are filtered from raw rows by graph and the actual raw qualifier prefix, ordered by raw edge ID, and constructed without deduplication. A minimal nonnegative-integer single-field ASCII qualifier grammar is proposed: raw None/empty text/{} and raw {"q":<digits>} (plus raw excluded temporal-prefix cases) derive omission/value rather than accepting parsed flags. Broader json.loads remains a provider and observation-only; more ordinary qualifier syntax can be added only if useful.

Prove node-before-edge ordering, each record's raw origin, complete selected-row emission under the stable-view frame, exact physical multiplicity, and counters equal emitted line kinds. A typed generated-event consumer derives import callback arguments/counters. Encoding/file parsing is a named ordinary codec law or separately checked finite grammar, with actual pinned JSON/file execution in the binding; no prepared parse answer. This does not promise storage inverse, caller transaction effects or persistent edge-key identity.
