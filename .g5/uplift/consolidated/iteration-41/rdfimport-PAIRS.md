# W47: import_rdf into the graph readers

Selected from the unbound public methods after iteration 40: `import_rdf` writes nodes, edges and properties, has no
binding, and its owner text (`install.import`, `install.export.rdf.content`) covers only commit granularity and the
graph-context round trip. Sources for the predictions: SEMANTIC_LAYER.md ("Importing RDF", "Named graphs") and the API
reference. Verus before: nothing for import (export is `rdf_reporting`).
