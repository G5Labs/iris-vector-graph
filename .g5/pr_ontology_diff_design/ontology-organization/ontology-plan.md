# Reorganizing the iris-vector-graph ontology

The reader should be able to start with a question such as “Which graph will this query read?” and find both the governing statement and its evidence. Today the root directs that reader to an ID prefix, and the two largest pages each serve several audiences. I propose organizing the reading paths around those questions while retaining the original statements as the authority.

I examined `consolidated_uplift` at `d87a22595`. The ontology describes IVG 4.7.0 at `3eaa79cf`. Its root already contains zero blocks. Its 13 subject pages contain 406 unique blocks, comprising 248 intent statements and 158 decisions. During inspection the branch advanced to `8ab0f2585` for iteration-60 ledger work. The ontology, statement crosswalk and model manifests matched the inspected revision at that commit. Refresh the inventory when implementation starts. Keep genuine parent and child commitments connected across pages. Give independent sections ordinary Markdown headings. The prose pass covers headings, definitions, short introductions and link labels. The original block wording, qualifications and evidence annotations stay intact.
