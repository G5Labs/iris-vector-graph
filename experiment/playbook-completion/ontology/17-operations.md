# 17 Operations and runtime

Module: OPS
Root: OPS-0
Scope: How operators and programs reach and run the product. The command line (iris_vector_graph/cli.py), the status report and admin helpers (status.py, capabilities.py, _engine/admin.py), the hosts and connections (host.py, embedded.py, _iris_compat.py), the SQL adapter and its protocol (stores/iris_sql_store.py, stores/lazy_kg.py, store_protocol.py), the HTTP client (sdk.py), index handles (index_config.py, index_protocol.py), the error types (errors.py, exceptions.py, result.py), helpers (dbapi_utils.py, utils.py, constants.py, models.py), the server code helpers Graph.KG.Meta, PyOps, SQL and JsonKeys, and the deploy recipes (docker-compose.yml, docker/, deploy/). It also holds the premises about the IRIS runtime and the Python dependencies (pyproject.toml, uv.lock). The algorithms the SQL adapter dispatches, the adjacency writers, setup and class deploy belong to other modules; this module states only how the adapter routes and guards them. Evidence note: a tested item under tests/unit runs on stand-ins with no IRIS unless its Notes say otherwise (one class in tests/unit/test_engine_status.py needs IRIS); items under tests/integration and tests/e2e need IRIS. No test was run for this module.
