# 09 Native Cypher executor

Module: NAT
Root: NAT-0
Scope: The native Cypher executor and everything that decides when it answers. Server code:
iris_src/src/Graph/KG/Cypher/Exec.cls (the interpreter, paging, workers), Cypher/Gen.cls (compiled plans, plan entries,
compile modes, DropAll), Cypher/Props.cls (the property reader), Cypher/SortKey.cls (sort keys) and
iris_src/src/IVG/CypherEngine.cls (Cypher from ObjectScript). Python: iris_vector_graph/cypher/native_plan.py (the
planner and the native gate), native_route.py (routes), native_shadow.py (the shadow comparison), and the native routing
lines of iris_vector_graph/_engine/query.py (execute_cypher's native branch, _try_native, _run_native_plan,
_shadow_compare, _routed_sql; the rest of query.py is another module's). The gate facts the engine caches live in
iris_vector_graph/engine.py and are cited here, not owned. The adjacency index itself (^KG), the degree cache and the
variable-length walk belong to other modules; this module reads them.
