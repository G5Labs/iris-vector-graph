# 18 Snapshots: saving and restoring a namespace's content

Module: SNP
Root: SNP-0
Scope: Saving a namespace's content to a ZIP archive and restoring it, replacing or merging: the store plan that ties the archive to Graph.KG.GraphStores, the tables, vector tables and globals it carries and leaves out, the layout check, the restore allow-list, the server-side value helpers, the HTTP endpoint, and what a restore does to the ledger and to stores the archive does not name. Production files: iris_src/src/Graph/KG/Snapshot.cls and the snapshot part of iris_vector_graph/_engine/snapshot.py (save_snapshot, snapshot_info, restore_snapshot and their helpers); the HTTP endpoint POST /admin/snapshot in iris_vector_graph/cypher_api.py. The same Python file also holds import_rdf, load_networkx, load_obo and the NDJSON import and export; those are import and export, not snapshots, and are not covered here.
