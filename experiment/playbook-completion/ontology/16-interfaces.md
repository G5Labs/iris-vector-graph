# 16 Interfaces and their security

Module: API
Root: API-0
Scope: The ways a caller reaches the product from outside a Python program: the sample FastAPI app (api/main.py,
api/dependencies.py, api/routers/cypher.py, api/routers/fhir_event.py, api/models, api/gql with core and resolvers),
the generated GraphQL server (iris_vector_graph/gql), the Cypher HTTP server and its admin routes
(iris_vector_graph/cypher_api.py), the Bolt server (iris_vector_graph/bolt_server.py), the shared key and read-only
gates (iris_vector_graph/api_auth.py, iris_vector_graph/_api_key.py), the SQL-name helpers
(iris_vector_graph/security.py, iris_vector_graph/routing.py), the REST dispatcher (Graph.KG.Service), the MCP classes
(Graph.KG.MCPService, MCPToolSet, MCPTools) and the demo servers (src/iris_demo_server, src/iris_fraud_server).
What each interface does with the graph a caller names is stated per interface and summed up under API-B15.
Also owns (assigned by the coverage reconciliation, ontology/reconcile-records.json): the stdio MCP server scripts/mcp/ivg_mcp_server.py and config/mcp-graph.toml (API-B80, API-T12.80), and the sample API's biomedical example types and loaders examples/domains/biomedical/types.py and loaders.py (API-B6.80 to API-T6.83).
