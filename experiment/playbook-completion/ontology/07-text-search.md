# 07 Text search and result fusion

Module: TXT
Root: TXT-0
Scope: BM25 lexical search and the fusion of ranked result lists. Owns iris_src/src/Graph/KG/BM25Index.cls (the
^BM25Idx global, its stopword list, the SQL function kg_BM25 it serves through Graph.KG.SqlProcs),
iris_vector_graph/text_search.py (TextSearchEngine) and iris_vector_graph/fusion.py (RRFFusion,
HybridSearchFusion). Covers the public commands that front them: the engine's bm25_build, bm25_search, bm25_insert,
bm25_delete, bm25_upgrade, bm25_drop, bm25_info, kg_TXT and kg_RRF_FUSE (iris_vector_graph/_engine/vector.py), the
operators shim and kg_RERANK, the generated SQL procedures kg_TXT and kg_RRF_FUSE (iris_vector_graph/schema.py), the
/hybridSearch route (Graph.KG.Service, Graph.KG.PyOps.HybridSearch), and the Cypher calls ivg.bm25.search and
ivg.retrieve (iris_vector_graph/cypher/translator.py). The docs table and its iFind index are created by module VEC
(migrations/docs_and_edge_vectors.py); this module reads them. Vector legs are module VEC's; this module states only
how they are fused.
