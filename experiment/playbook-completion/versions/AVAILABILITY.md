## Notes

- The 2026.2 container is this lane's own, so its runs took no audit lock. Every audit-container command ran under
  `tools/locks.sh iris` with at most 4 connections at once. The audit container was not restarted or reconfigured
  beyond the disposable user and role and their SQL grants.
- Driver 5.4.0 is a different build of the same package. Its `iris.dbapi.connect` returns `iris.dbapi.IRISConnection`
  (5.3.2: `iris._elsdk_.IRISConnection`). Both builds expose `autocommit`, so the pin's
  `_write_txn._driver_autocommit_off` reads the same values with either (`$RUN_DIR/versions/logs/autocommit-probe-*.log`).
