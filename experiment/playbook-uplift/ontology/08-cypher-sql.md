# 08 Cypher on the SQL path

Module: CYP
Root: CYP-0
Scope: Cypher (and the AQL dialect) on the SQL path: lexing, parsing, translation to SQL, reads, writes (CREATE, MERGE, SET, REMOVE, DELETE, FOREACH), all-graphs reads and writes, procedures, functions, parameters, read-only mode, errors and refusals. Production files: iris_vector_graph/cypher/ (lexer.py, parser.py, ast.py, translator.py, merge_rows.py, row_where.py, count_create.py, read_only.py, procedure_signatures.py, algorithms/, aql/), iris_vector_graph/_engine/query.py (the query facade; its native-routing parts belong to the native executor module), the Cypher write transaction in iris_vector_graph/stores/iris_sql_store.py (execute_transaction), iris_src/src/Graph/KG/CypherFn.cls, iris_src/src/IVG/Percentile.cls, iris_vector_graph/operators.py and sql/operators.sql. translator.py (31,908 lines) is covered at breadth: feature classes, refusals, documented semantics and known gaps, not line by line.
