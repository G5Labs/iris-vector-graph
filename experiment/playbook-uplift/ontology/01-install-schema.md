# 01 Install, schema and upgrades

Module: INS
Root: INS-0
Scope: Setup of a namespace and its upgrades. The schema name and its record (iris_vector_graph/schema_name.py), setup
itself (initialize_schema and its helpers in iris_vector_graph/_engine/schema.py; the DDL, the deploy entry, the 3.2.0
edge rescue and the graph_id upgrade steps in iris_vector_graph/schema.py), the class deploy
(iris_vector_graph/_engine/class_deploy.py), the routine record (iris_vector_graph/routine_record.py), the legacy
objects (iris_vector_graph/legacy_manifest.py, legacy_bodies.py, legacy_text.py, iris_vector_graph/_engine/legacy.py),
the migration package except the four step modules other modules own (iris_vector_graph/migrations/__init__.py,
_commit.py, statements.py, upgrade.py), the SQL files under sql/, and the server classes Graph.KG.SqlPrivilege and
Graph.KG.SqlProcs. The vector width rules of setup are stated in module VEC; the adjacency hooks in ADJ; the dropping of
compiled query classes in NAT. Evidence is reading at pin 3eaa79cf. Unit tests named here run on fakes and inspect
Python or source text; e2e and integration tests need a live IRIS and were opened, not run.
