# 06 Vectors and vector search

Module: VEC
Root: VEC-0
Scope: Embeddings and vector search. Owns the embedding registry (Graph_KG.embedding_registry, its model key and
width per table and graph), the routed per-graph vector tables (kg_emb_<hash> for nodes, kg_eemb_<hash> for edges)
and the three legacy tables (kg_NodeEmbeddings, kg_NodeEmbeddings_optimized, kg_EdgeEmbeddings), the quarantine
(Graph_KG.embedding_quarantine), the vector indexes (HNSW on routes; ^IVF through iris_src/src/Graph/KG/IVFIndex.cls;
^VecIdx through iris_src/src/Graph/KG/VecIndex.cls; ^PLAID through iris_src/src/Graph/KG/PLAIDSearch.cls), the embed
queue (^EmbedQueue through iris_src/src/Graph/KG/EmbedQueue.cls and iris_src/src/Graph/KG/EmbedQueueTask.cls), and
the Python that fronts them: iris_vector_graph/embedding_identity.py, iris_vector_graph/embed_selector.py,
iris_vector_graph/_engine/vector.py (vector parts; kg_TXT, bm25_* and the text leg of kg_RRF_FUSE are module TXT),
iris_vector_graph/_engine/embeddings.py, iris_vector_graph/vector_utils.py, iris_vector_graph/_widths.py and the 4.0.0
steps iris_vector_graph/migrations/graph_scoped_embeddings.py, iris_vector_graph/migrations/docs_and_edge_vectors.py
and iris_vector_graph/migrations/kg_node_stores.py. The registry's persistence half lives in
iris_vector_graph/_engine/schema.py (read here, owned jointly with setup), and the generated kg_KNN_VEC procedure in
iris_vector_graph/schema.py. Erasure of routes is module ERS (Graph.KG.Eraser); this module states only what it needs.
