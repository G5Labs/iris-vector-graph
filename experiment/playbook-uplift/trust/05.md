# Premises: 05 Temporal edges and the temporal index

None of these is checked in this uplift; each names the check that would.

### P-0501 $Increment is atomic across processes
- Statement: concurrent `$Increment` calls on one global node never lose an update.
- Used by: `TemporalIndex.WriteStores` (`^KG("bucket")`, the `tagg` count and sum). min and max are read then set with
  no lock, so two writers can race on them; that is not covered by this premise.
- Check: documentation; a two-process write of the same bucket compared with the edge count.

### P-0502 A process-private global disappears when its process ends
- Statement: `^||` globals belong to one process and are freed when it ends.
- Used by: the window reader's state (`^||IVG.TWin`), the purge staging (`^||IVG.TPurge`, `^||IVG.TNodes`) and the row
  drop's list (`^||IVG.DropRows`).
- Check: live (`tests/e2e/test_255_window_reader_us2_e2e.py::test_an_abandoned_reader_is_freed` observes it upstream).

### P-0503 IRIS collates canonical numbers before strings
- Statement: in a global's subscripts every canonical number sorts before every string.
- Used by: `TemporalWindow.RangeSafe` and `NextKey` (a numeric-looking prefix has no contiguous range).
- Check: documentation; `test_numeric_sources_collate_before_strings_and_a_prefix_still_finds_them` upstream.

### P-0504 A global value keeps its number or string type
- Statement: a value set as a number reads back as a number (`$ListBuild` encodes it as one) and a value set as a
  string reads back as a string, even when its text is numeric.
- Used by: `TemporalWindow.Row` and `TemporalIndex.GetEdgeAttrs` to return attribute values with their written type.
- Check: live, the comment says on IRIS 2026.3; not run here. A snapshot round trip writes every value as text
  (finding F-1804).

### P-0505 The tzdata wheel is installed
- Statement: the `tzdata` package (2025.2 or later) is importable wherever the product runs.
- Used by: `iris_vector_graph/_tz.py` (`zone`), and through it every Cypher named-zone conversion.
- Check: `pyproject.toml` lists it as a dependency; a vendored or stripped install would fall back to the host.

### P-0506 An IRIS string holds at most 3,641,144 characters
- Statement: building a longer `%String` raises `<MAXSTRING>`.
- Used by: the cap of `QueryWindow`, `QueryWindowInbound`, `export_temporal_edges_ndjson` and the Python migration;
  `TemporalWindow.PAGECHARS` stays below it.
- Check: live (`test_get_edges_in_window_raises_past_the_string_limit` upstream).
