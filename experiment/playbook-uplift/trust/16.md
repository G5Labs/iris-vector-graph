# Premises of module 16 (interfaces)

Premises the interface statements rest on. None is checked in this uplift; "Check" says how one could be.

### P-1601 IRIS Community has none of the %AI classes the MCP classes extend
- Statement: IRIS Community 2026.1 ships no `%AI.MCP.Service`, `%AI.ToolSet`, `%AI.Tool` or `%AI.Policy.ConsoleAudit`;
  only AI Hub builds do. So `Graph.KG.MCPService`, `MCPToolSet` and `MCPTools` cannot compile there, and setup skips
  them with a reason (`iris_vector_graph/_engine/class_deploy.py:76-104`).
- Used by: API-P12.1 and the MCP tool set cells (Community build is `n/a`).
- Check: `docs/ADMIN_GUIDE.md:353` states it; `tests/unit/test_460_r272_tcp_deploy_skips.py` checks the skip logic
  with a stubbed class probe (unit); `tests/e2e/test_470_setup_compiles_every_class_e2e.py` would observe it live.

### P-1602 The MCP tools find the product's Python package in IRIS's embedded Python
- Statement: `MCPTools` methods import `iris_vector_graph` inside IRIS. Setup does not install it; an operator puts it in
  `<install-dir>/mgr/python` at the application's version.
- Used by: API-P12.2.
- Check: documentation only (`docs/ADMIN_GUIDE.md:793-820`, SmokeTest).

### P-1603 An operator configures the MCP web application's login and roles
- Statement: the product ships no `CreateWebApp` for the MCP service. Who may call the tools, and with which IRIS user,
  is set by the operator in IRIS (web application authentication, MatchRoles) and in the MCP server.
- Used by: API-P12.3; every MCP statement about power (RunSQL, LoadGraph) assumes a trusted client.
- Check: documentation only (`docs/ADMIN_GUIDE.md:634-638`).

### P-1604 `hmac.compare_digest` takes time independent of where two equal-length inputs differ
- Statement: Python's `hmac.compare_digest` on bytes does not return early on the first differing byte. It may still
  reveal the lengths.
- Used by: API-I1.4.
- Check: Python documentation; the unit test only checks that the function is called.

### P-1605 Two threads must not share one IRIS DB-API connection
- Statement: the IRIS DB-API driver declares `threadsafety = 1`. Two threads using one connection at once can lose a
  statement handle (observed as SQLCODE -400 in CHANGELOG 4.6.5, on IRIS 2026.3.0AI.154, driver 5.4.1).
- Used by: API-B4.5 / F-1608; API-T8.2.
- Check: `tests/e2e/test_465_api_engine_lock_e2e.py` style probe (live), run against the sample API.

### P-1606 A TLS proxy fronts any server another machine can reach
- Statement: none of the servers (sample API, Cypher HTTP server, Bolt TCP listener, generated GraphQL server, fraud and
  demo servers) terminates TLS. The API key, Bolt credentials and FHIR basic-auth pass in clear text unless an operator
  puts a TLS proxy in front.
- Used by: API-P1.14.
- Check: deployment review; not in the product.

### P-1607 A CSP request stream's `Read()` with no length returns at most 32,000 characters
- Statement: `%Stream.Object:Read(len)` defaults `len` to 32000, so `%request.Content.Read()` returns at most the first
  32,000 characters of a longer body.
- Used by: API-B11.12 / F-1612.
- Check: live: POST a `/vectorSearch` body over 32,000 characters (for example a 3,072-wide vector at full precision)
  and see whether `%FromJSON` fails.

### P-1608 Python salts `hash()` of a string per process
- Statement: with hash randomization on (the default), `hash(str)` differs between interpreter runs.
- Used by: API-T9.13 (Bolt node and relationship numbers change across restarts).
- Check: Python documentation (`PYTHONHASHSEED`).

### P-1609 Each IRIS connection counts against the instance's connection and licence limits
- Statement: every Bolt session opens its own IRIS connection, and IRIS Community admits only a few at once (the code
  comments assume five: `api/gql/schema.py:51-56`, `iris_vector_graph/gql/pooling.py:7-11`).
- Used by: API-T8.3.
- Check: live: open sessions until IRIS refuses; the generated GraphQL server maps "License Limit" to 503.

### P-1610 An ASGI server answers a WebSocket closed before accept with HTTP 403
- Statement: when `ApiKeyMiddleware` sends `websocket.close` before `websocket.accept`, uvicorn refuses the upgrade with
  HTTP 403.
- Used by: API-X1.6.
- Check: `tests/unit/test_r097_api_key_every_route.py::test_every_websocket_route_refuses_an_upgrade_without_the_key`
  (Starlette TestClient, not uvicorn).

### P-1611 IRIS web applications enforce their authentication setting before the dispatch class runs
- Statement: `AutheEnabled = 32` means password authentication, and `MatchRoles = ":IVG_KG_<NS>"` adds that role to
  each user the application authenticates; an unauthenticated request never reaches `Graph.KG.Service`.
- Used by: API-P11.2, API-B11.1.
- Check: `tests/e2e/test_460_kg_webapp_least_privilege_e2e.py` (live) shows a user without the role gets no answer.

### P-1612 Neo4j drivers rely on Bolt transactions and on PULL's has_more
- Statement: the Bolt protocol defines BEGIN/COMMIT/ROLLBACK as an explicit transaction whose writes a ROLLBACK
  discards, and PULL {n} as returning at most n records with `has_more: true` when more remain. Drivers (for example
  the Python driver's managed transactions and its fetch size of 1,000) are written against that.
- Used by: API-B9.10 / F-1601, API-B9.11 / F-1602.
- Check: https://neo4j.com/docs/bolt/current/ ; a live driver test against the Bolt server.
