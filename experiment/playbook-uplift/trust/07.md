# Trust: module 07 (text search and fusion)

Premises the TXT statements rely on. None is checked by this uplift; each says what would check it.

### P-0701 The IRIS English analyzer splits text into lower-case words as documented
- Statement: `%iFind.Utils.Analyze(text, "en", 1)` returns a `$List` of tokens that breaks at spaces and punctuation,
  keeps accents and does no stemming (USER_GUIDE examples: `state-of-the-art` is four tokens, `don't` is `don`, `t`).
  When the class is absent or raises, `Graph.KG.BM25Index.Tokenize` falls back to runs of letters and digits.
- Used by: TXT-T1.2, TXT-P1 (every BM25 document and query).
- Check: documentation only; a live probe of `Analyze` on the USER_GUIDE examples would check it per IRIS build.

### P-0702 TROLLBACK undoes plain Set and Kill but not $Increment
- Statement: inside TSTART, a rollback undoes global `Set` and `Kill`; `$Increment` is not undone (ADR-0007 cites a
  measurement made in spec 236).
- Used by: TXT-B4.5 (BM25 Insert and Delete use plain Set so a failed write rolls back as a unit).
- Check: upstream live test `tests/integration/test_044_bm25_incremental.py::test_a_failure_inside_the_write_rolls_the_index_back_and_releases_the_lock`
  (not run here).

### P-0703 A timed LOCK gives up after its timeout and reports it in $Test
- Statement: `Lock +^BM25Idx(name, "lock"):wait` returns with `$Test = 0` when the lock is not granted within `wait`
  seconds, and holds nothing.
- Used by: TXT-X6, TXT-X8.
- Check: upstream live tests `test_a_writer_that_cannot_get_the_lock_raises_and_changes_nothing` and
  `test_an_upgrade_that_cannot_get_the_lock_raises_and_clears_its_flag` (not run here).

### P-0704 Process-private globals are visible to their own process only
- Statement: `^||name` globals belong to one process and are removed when it ends; no other process reads them.
- Used by: TXT-B2.14 (Search's score and sort arrays, SearchReport's skipped-term list).
- Check: IRIS documentation only.

### P-0705 Integer subscripts collate by numeric value
- Statement: canonical integer subscripts, including large ones such as a score times 10^12, are ordered by value by
  `$Order`, so walking `^||bm25sorted` backwards yields scores from high to low.
- Used by: TXT-B2.11.
- Check: IRIS documentation; an upstream live test checks score order (`test_scores_follow_the_bm25_formula_when_document_lengths_differ`).

### P-0706 IRIS binds an empty host variable as SQL NULL
- Statement: an empty string passed as a parameter reaches SQL as NULL, so `col = ?` never matches the default graph;
  the code wraps both sides in `COALESCE(..., '')`.
- Used by: TXT-B1.3, TXT-B12.1 (Build's node query, kg_TXT's graph predicate).
- Check: stated in code comments (BM25Index.cls Build, schema.py kg_TXT); not checked here.

### P-0707 The iFind index on the docs table may be absent
- Statement: `idx_docs_text_ifind` exists only where setup created it and the IRIS build carries iFind; a statement
  naming it otherwise fails with SQLCODE -151 or -359, and a deleted generated class gives -149.
- Used by: TXT-B12.5 (kg_TXT's LIKE fallback).
- Check: upstream live tests `tests/e2e/test_230_ifind_helper_repair_e2e.py` (not run here).
